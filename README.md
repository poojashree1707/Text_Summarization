## Text Summarization AI

### About the Project

#### Text Summarization AI is a simple web application that summarizes long text into a short and meaningful paragraph. It uses Natural Language Processing (NLP) and a pre-trained Transformer model to generate summaries automatically.

### Features

* Summarizes long paragraphs and articles.

* Generates short and meaningful summaries.

* Simple and user-friendly interface.

* Uses a pre-trained AI summarization model.

* Displays the generated summary on the same page.

* Dark purple and blue theme.

### Project Structure

Text summarization

├── app.py

├── requirements.txt

### How to Use

* Open the Text Summarization AI application.

* Paste a paragraph or article into the text input box.

* Click the Summarize button.

* Wait for the AI model to process the text.

* View the generated summary.
